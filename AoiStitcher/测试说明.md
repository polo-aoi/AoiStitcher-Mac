# AoiStitcher 3.0 测试说明

默认打开「长图拼接」，顶部第二个标签为「自由画布」。两个模式使用相同的侧栏、工具栏、外观切换和导出控件，双击照片进入同一个裁剪工作台。标题栏齿轮进入「软件设置」，菜单栏也可以打开「关于 AoiStitcher」和「支持作者」。

## 裁剪

1. 拖动裁剪框的四角或四边手柄调整范围；选择「自由」可以独立改变宽高，选择「原图」或固定比例则保持对应长宽比。按 Shift 临时保持比例。
2. 在框内拖动照片调整构图。照片保持覆盖裁剪范围，到边缘时停止；先缩小裁剪范围或提高「照片」缩放，就有更多可移动空间。Command 加拖动可以移动裁剪框。
3. 双指捏合改变照片大小；普通滚动移动照片。Option 加滚轮缩放预览，空格加拖动平移预览；「适合窗口」恢复预览位置。这些预览操作不会改变导出尺寸。
4. 裁剪框顶部外侧有旋转手柄，框外缘也能按住拖动旋转；旋转光标区负责连续微调角度，Shift 以 15 度为单位。照片围绕裁剪框中心旋转，裁剪框位置保持不变。选择「拉直」，沿照片中的水平线或竖线拖出参考线，松开后自动校正；也可用拉直滑块或角度输入框精调。侧栏旋转按钮每次旋转 90 度，双向箭头互换裁剪框宽高。
5. 水印工具支持选择、拖动、角点缩放和顶部手柄旋转，侧栏也能调整数值；Delete 删除选中的水印。
6. ⌘Z 撤销、⇧⌘Z 重做，一次拖动对应一次撤销；「重置裁剪」恢复完整原图。回车应用、Esc 取消。保存使用原图像素，重新进入后仍能继续编辑。

裁剪和水印的输出限制为单边不超过 16384 像素、总计不超过 6400 万像素。

## 自由画布

底部操作栏只保留「清空画布」、导出图片和导出设置按钮。导出设置中可以调整宽度与 PNG/JPEG，并单独恢复默认设置；软件设置中的恢复按钮会同时恢复外观和记住的文件夹。导出成功后可以选择保留当前画布，或直接清空后开始下一组。

「画布」比例旁的双向箭头互换宽高，例如 3:2 切换成 2:3；也适用于自定义尺寸。照片保持大小与旋转角度，未锁定素材相对画布中心的位置保持不变。可用撤销恢复。

1. 点击「添加照片」选择两张图片。首次导入会自动左右排；也可以从 Finder 拖入，多于两张仍能使用。
2. 在「快捷排版」设置留白、间距、两图区域比例，再点击左右排或上下排。后续可以自由移动素材。
3. 点击「添加纸张」添加纯色色纸、米色纸、纤维纸、方格纸，或者导入自己的底图。
4. 点击素材后拖动位置、拉角缩放、拉顶部圆点旋转。照片与导入底图保持长宽比，纯色色纸可改变宽高。按 Shift 旋转时以 15° 为单位。
5. 素材列表单击只选中素材，右击（或 Control 加单击）打开独立参数面板；画布上的素材也可以右击设置。面板可改颜色、位置、大小、旋转等，点击「完成」或面板外关闭，不会挤走素材列表。
   在素材列表拖动行，按插入线调整上下顺序，越靠上越在前面；排序支持撤销。单击选中素材后按 Delete 直接删除，Fn + Delete 也可使用，⌘Z 可恢复。锁定素材不能删除或拖动排序。列表获得焦点时，⌘I 打开参数，⌥↑／⌥↓ 上下移动图层。
6. 双击照片或点击「裁剪与水印」进入新版裁剪工作台。
7. 空格加拖动平移画布，Option 加滚轮或双指捏合缩放，Q 适合窗口。方向键移动选中素材，Shift 加方向键移动 10 像素；Delete 删除；⌘D 复制；⌘Z 撤销；⇧⌘Z 重做。这些快捷键在画布获得焦点时生效。
8. 选择 PNG 或 JPEG，填写导出宽度，导出图片。超出画布的素材部分自动裁掉，选择边框和操作手柄不会导出。

此版画布在当前会话内编辑，关闭窗口后不会保存排版工程。请在退出前导出图片。

构建要求 Xcode 26.2。运行要求 macOS 14.6 或更高，App 包含 arm64 和 x86_64；未使用 Developer ID 签名和公证。

本地检查：运行 `zsh scripts/test-canvas.sh`。
重新构建通用 App：运行 `zsh scripts/build-universal.sh`，或传入自定义导出目录。
