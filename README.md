# aoipic 3.2.2

在现有 AoiStitcher 工作树上持续开发的原生 macOS 应用。保留长图拼接、双图拼接、自由画布、纸张库、裁剪与水印、图片压缩和旧设置；3.2.0 新增独立的标准拼图工作区。

3.2.1 修复标准拼图的空状态文字重叠；均衡网格置首并作为初始布局。选中照片可打开单图工具，进行裁剪 / 水印、单格替换、交换位置和重置取景；普通拖动仍用于格内取景。画布样式提供恢复默认按钮（间距 8、留白 16、圆角 0、白色底色，保留背景图片）。标准拼图始终在网格中编辑，任意位置摆放请切换自由画布。

3.2.2 精简标准拼图界面：布局模板移到左侧，移除重复的图片列表、单图参数区和比例选择区。画布顶部以加减按钮调整格子数；删除单张照片保留空格，减少有照片的格子先确认。照片旁的工具栏集中提供裁剪 / 水印、替换、交换、填充方式、重置取景与删除。

当前交互调整：标准拼图直接左键拖动照片到另一格交换位置，右键拖动调整框内取景，移除工具栏的交换按钮。长图和标准拼图各自提供互斥的右键 / 键盘拖拽设置，默认右键；选择键盘后才显示具体按键选项。

## 使用

顶部切换「边框水印」「双图拼接」「自由画布」「长图拼接」「图片压缩」「标准拼图」。边框水印工作区提供有限的内置边框、批量素材列表和“提交效果 / 点餐”入口；在设置中填写联系邮箱后，提交窗口点击“确定”会自动复制邮箱并显示反馈。压缩页多选导入图片或文件夹，也可从 Finder 拖入右侧列表。选择朋友圈、小红书、抖音或自定义，调整输出锐化，选择输出位置，然后点击「导出图片」。列表支持多选、移除所选、Delete、清空。导出期间显示文件名与进度，可停止；失败行可打开详情并单独重试。

朋友圈/小红书/抖音的质量自动决定，不提供质量选择；短边分别为 1920/2560/2160 px，小图不放大。抖音参数依据本机图适 4.7.1 的场景分支核对，详见 `AoiStitcher/Compression/抖音参数核对.md`。五档是输出锐化。自定义可调整尺寸、格式和质量；底部导出设置可调整拍摄信息、GPS、允许放大和导出后显示。没有图片预览、原图显示或前后对比。

## 标准拼图

- 支持 1–16 格，按格数筛选模板；2–16 格各有六种自主实现的切分树布局。照片按顺序放入格子，切换模板保留照片。
- 支持八种画布比例，画布居中适应窗口；拖动内部公共分割线，所关联的一组格子实时联动。分割树限制最小格子尺寸。
- 单击照片选中，左键按住照片拖到另一格交换照片及其取景、裁剪和水印；默认右键拖动调整框内取景，滚轮或触控板捏合缩放。工具栏不再提供交换按钮。点击画布留白会取消选中并收起工具栏。
- 「软件设置 → 标准拼图」可将框内取景切换为按住空格、Option、Command 或 Control 加左键拖动；右键与键盘方式互斥，选定键盘方式才显示按键选择。普通左键拖动始终用于交换格子里的照片。
- 裁剪 / 水印沿用现有单图编辑器，从原图打开并保留编辑参数；保存结果单独缓存，导出使用完整编辑结果，原文件保持不变。替换照片只作用于当前格，重置该格取景，取消或读取失败保留原照片。
- 支持填满或完整显示、间距、外留白、圆角、背景色与背景图；左侧用实时绘制的缩略图选择模板。
- 导出 PNG / JPEG，按设定比例读取原图生成结果；原图移位或失效会显示具体文件名。已有目标文件不会被覆盖。

模型、模板、渲染器和 macOS 界面分别位于 `GridCollageModel.swift`、`GridCollageTemplates.swift`、`GridCollageRenderer.swift`、`GridCollageView.swift`。模型和渲染器不依赖 AppKit；当前只提供 macOS 界面。参考拼图大师公开页面的功能，自主实现，未复制其脚本或素材。当前模板均为嵌套横纵切分；尚不包含斜线、曲线或无法用切分树表达的交错布局，也不宣称已复现网站全部功能。

## 长图拖拽设置

长图默认右键拖动整个画布，左键拖照片调整顺序。「快捷键与导出」中可改为按住键盘快捷键加左键拖动画布；两种方式只能选择一种，顶部提示只显示当前生效的方式。选择键盘方式后可选空格、Option、Command 或 Control。标准拼图的框内取景快捷键独立保存，不会随长图设置改变。旧版本同时开启两种方式的设置会迁移为默认右键；旧版本只开启键盘方式则保留原来的按键。

## 兼容性

应用显示名和构建产物为 `aoipic`。为保留旧设置与 Xcode 工程兼容，bundle ID `polo-aoi.AoiStitcher`、`AoiStitcher.xcodeproj`、scheme 和旧偏好键保持不变。现有画布在会话内编辑，原工程没有磁盘工程文件保存功能；此次没有引入或更改工程文件格式。新版本未加入画布自动保存。

压缩模块的来源、算法保留项与架构说明见 `AoiStitcher/Compression/README.md`。该实现不宣称已经与图适完全一致。

## 构建和验证

要求 Xcode 26.2；运行最低 macOS 14.6。构建 arm64 + x86_64 通用包，使用本机 ad-hoc 签名，未做 Developer ID 公证。

```sh
zsh scripts/test-canvas.sh
zsh scripts/test-compression.sh
zsh scripts/test-grid-collage.sh
zsh scripts/test-grid-collage-render.sh
zsh scripts/build-universal.sh /Users/aduo/Documents/AoiPic
```

构建脚本会保留输出目录中已有的 aoipic.app 到单独的 previous-build 目录，不静默覆盖。

本次没有移动端、收费、100 张额度或云同步；代码和图片处理均在本机。纸张库支持本地导入、保存、分页、排序和拖入画布，纸张底图最多 5 层且始终位于照片图层下方。边框工作区的批量边框渲染、水印库和多级资源文件夹仍在后续阶段。
