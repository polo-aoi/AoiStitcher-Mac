# AoiStitcher 3.3.0

原生 macOS 拼图应用，包含「项目素材」「标准拼图」「自由画布」「长图拼接」四部分。可先以项目素材库组织照片，再选择工具完成拼图；照片已经选好时，也可从首页直接进入拼图。双图拼接并入自由画布，保留左右排、上下排等快捷排版，以及纸张库、裁剪、水印和旧设置。

应用名称恢复为 AoiStitcher。边框工作区已移除；图片压缩与输出锐化移至独立应用 **AoiGlow**，工程位于 `/Users/aduo/Documents/aoiglow`。主程序保留旧项目和素材资料，也保留旧项目中的压缩导出历史。

标准拼图布局模板位于左侧，画布顶部以加减按钮调整格子数；删除单张照片保留空格，减少有照片的格子先确认。照片旁的工具栏集中提供裁剪 / 水印、替换、填充方式、重置取景与删除。画布样式可恢复默认（间距 8、留白 16、圆角 0、白色底色，保留背景图片）。

当前交互调整：标准拼图直接左键拖动照片到另一格交换位置，右键拖动调整框内取景，移除工具栏的交换按钮。长图和标准拼图各自提供互斥的右键 / 键盘拖拽设置，默认右键；选择键盘后才显示具体按键选项。

## 使用

启动后显示项目首页，顶部是左右等宽、等高的虚线圆角卡片。左侧「创建图片项目」用于先整理、挑选和分组，再拼图；整块可点击选择文件夹或多选图片，也可直接拖入文件夹或图片，照片保留在原始位置。不再提供右上角新建按钮、仅填写名称的创建窗口或其他空项目创建入口。导入文件夹时使用文件夹名称创建项目。双击项目卡片进入项目素材，单击不打开；右键仍可选择「打开」。项目按创建时间从新到旧固定排列，卡片显示创建日期；打开、浏览、编辑及重命名都不改变顺序，新项目插入列表前方。

右侧「直接开始拼图」提示「无需创建项目，进入后即可添加照片」，提供「标准拼图」「自由画布」「长图拼接」三个入口。点击按钮直接进入对应的空编辑器，再使用工具内的导入按钮或从访达拖入图片；首页也可把图片拖到对应按钮，带图进入工具。标准拼图最多 16 张，首页拖入无效内容或超过上限时保留首页，不新增项目。直接拼图时顶部仅显示三个工具；当前会话内可切换工具。空编辑器可直接返回首页，有尚未导出的作品时会先确认。此入口不保存项目或编辑草稿，完成后请导出成品。

首次进入或返回首页时，项目卡片不自动显示蓝色焦点框；实际单击卡片或主动按 Tab 导航后才显示，双击打开保持。悬停「创建图片项目」整卡或右侧三个拼图按钮时，底色与边框加深，图标轻微放大，约 0.15 秒过渡；不改变布局或拖入范围，并遵循系统「减少动态效果」设置。

主窗口原生标题栏右侧始终保留一个设置齿轮，在首页、项目素材及三个拼图工具中均打开同一「软件设置」窗口，⌘, 也可打开。各编辑器侧栏顶部只保留添加照片／纸张等操作，移除重复的应用名称、日夜切换和局部设置齿轮。外观与关于信息集中在设置的「通用」页；更改外观同步到所有页面，返回工具保留当前编辑内容。

已有项目可拖入图片、文件夹，或点击「导入素材」；文件夹及子文件夹按自然名称顺序读取，跳过非图片、隐藏文件、资料包和符号链接。同一批拖入的重复路径只导入一次。项目只记录原图位置，不复制或移动原文件。原图移动后可在首页右键「修复项目…」，选择新位置重新连接。

首页右键「在访达中显示」会定位最初导入的原始文件夹，照片都在子文件夹中时也保留导入根目录；多个来源可定位多个文件夹。旧项目根据已记录的原图路径定位其所在文件夹。没有可用原始位置时显示提示，不会打开软件内部的 UUID 项目资料目录。封面预览与素材缩略图统一写入隐藏的 `.thumbnails/v2` 缓存目录。

中间显示全部未分组素材，网格随容器宽度自动换行，只纵向滚动。支持 Shift／⌘ 点击切换选择、框选和多张拖动排序，拖动时显示插入位置。窗口或分栏变窄不会产生横向滚动条，缩放和换行不改变保存的顺序。「整理对齐」回到排列起点。单张或多张照片均可从素材区拖入已有组、从一个组拖到另一个组，或从组内拖回素材区；已有组的照片区、组号及行内留白都属于该组的追加区域。选中一张或多张照片，拖到右侧照片组区域的组外空白处、按回车或使用素材右键「新建组」，即可新建一组，这些照片离开原区域。空列表、组间空隙和末组下方空白均可接收单张或多张照片建组；未选择有效项目照片时不建组，访达文件及整组排序载荷不用于空白建组。组内可以选照片、拖动排序，按 Delete 按素材原顺序归还；点击组号选择整组后同样可按 Delete 归还，空组自动消失。组顺序和成员顺序自动保存，⌘Z 可撤销。

工具栏提供「素材滑块＋锁头＋分组滑块」。默认锁定，任一滑块同步调整两区；解锁后独立调整，重新锁定时先保留两边大小，下次拖动才以该侧数值同步。两侧大小与锁定状态随项目保存，旧项目继承原缩略图大小并默认联动。素材区触控板捏合等同调整左滑块，遵循锁定状态。组行高度随右滑块变化；图片内边距为 3pt，组内卡片间隔为 2pt，素材网格间隔为 6pt。缩略图尺寸及完整显示比例保持不变，竖图仍会保留比例带来的留白。拖拽预览使用当前显示尺寸和鼠标抓取位置，多张显示叠放与数量。照片不叠加导出角标；星级与颜色标签已移除。悬停可查看处理状态，素材信息弹窗已移除。选中照片按空格打开原图快速预览，多选可逐张浏览，再按空格或 Esc 关闭，保留原选择和查看位置。

「添加至」的标准拼图、自由画布、长图拼接三个按钮固定在右侧「照片组」标题下方，位于分组滚动列表之外；滚动组列表时按钮保持原位，右栏变窄时自动换行。素材区选中的照片、组内选中的照片和点击组号选中的整组都使用这组按钮，也可直接拖到对应按钮发送；窗口底部不再重复显示添加按钮。点击组号选择全部组员时，组号高亮为蓝色，照片分别显示圆角选框；整行保持普通浅灰圆角边界和正常底色，不增加整行蓝色外框或蓝色底色。组号、组行空白及实际照片的右键菜单统一为四项：添加至标准拼图、自由画布、长图拼接，以及「移回素材」。右击组号或行内空白时，四项操作作用于右击的整组；右击实际照片时，沿用照片选择规则，作用于所选照片。组内右键不再显示撤销、导入及旧组管理选项，中间素材区右键菜单保持。素材区或组行获得焦点时，1／2／3 仍分别添加选中照片至三个工具；点击组号后可快捷发送整组。也可把中间照片拖入已有组、将组内照片拖回中间。中间区域 Delete 从项目移除，右侧 Delete 仅退回素材；均可撤销且保留原文件、旧项目已有副本和导出历史。访达图片可直接拖入三个拼图工具。

所有添加入口共用同一流程：空工作区直接导入；已有内容时，在同一窗口确认本批顺序，并选择「继续添加」「清空后导入」或「取消」。窗口说明当前内容是否有尚未导出的修改；替换会先检查新图片，失败时保留旧内容；标准拼图追加超过 16 张时停用追加。取消保留素材选择、位置和原编辑内容。

成功导出的用途记录和悬停处理状态保留，取消或失败不增加记录；旧项目的导出历史继续兼容保存。项目素材已移除「筛选」按钮、条件弹窗及按拼图方式／导出状态筛选的逻辑，中间区域始终显示全部未分组素材。导出记录页面和入口继续保持移除。照片历史与工作区当前状态分别记录：修改作品后重新提示待导出，选中、缩放查看和平移视图不影响处理状态。标准拼图按格数筛选布局模板的功能保持。

项目名称、四个功能入口和两侧栏按钮合并在同一行。左侧按钮展开项目列表以切换项目，列表同样按创建时间从新到旧排列；创建项目统一回到首页使用虚线导入区。右侧按钮展开／收起照片组，收起后按回车建组会自动展开。分界线平时为 1px 浅灰线，悬停／拖动时为 3px 主题色线，并显示系统左右调整光标；8pt 可抓取范围，松手记住宽度，窗口变窄不覆盖宽度偏好。项目列表、素材区和照片组使用无背景轨道的半透明圆角悬浮滚动条，不挤占布局，滚动或悬停时显示。素材工具栏已移除名称搜索框与素材筛选，「导入素材」「整理对齐」依次靠左，双缩略图滑块靠右；撤销使用 ⌘Z。功能默认顺序为「项目素材」「标准拼图」「自由画布」「长图拼接」。在「软件设置 → 通用 → 顶部功能排序」中拖动条目或点击上下箭头，可调整后面三个入口的顺序，立即生效并在重启后保留；点击「恢复默认顺序」会回到上述排列。旧排序自动忽略边框、压缩及重复入口，保留其余工具的自定义顺序并补齐缺失项。排序时保留当前工作区与各工作区已经导入的素材和编辑状态。

## 自由画布与快捷排版

自由画布默认鼠标滚轮围绕指针缩放，右键拖动平移，右键单击照片打开素材设置。触控板双指滚动默认平移，捏合缩放。「软件设置 → 自由画布」可独立调整滚轮与连续滚动行为、缩放灵敏度和方向，以及右键／快捷键加左键的互斥平移方式；发送连续滚动事件的触控鼠标可将连续滚动设为缩放。画布绘制限制在编辑视口内，缩放和平移不会覆盖工具栏。

双图和多图在同一个「自由画布」中编辑，侧栏始终保留「快捷排版」。一至两张照片可设置留白、间距，再左右排或上下排；两张照片还可调整两图区域比例。排版后仍可直接移动、缩放和旋转照片。导入第三张及更多照片时继续留在当前画布，通过自由摆放编辑，快捷排版按钮停用。照片、纸张、裁剪、水印、撤销与导出沿用同一套编辑状态。

## 标准拼图

- 支持 1–16 格，按格数筛选模板；2–16 格各有六种自主实现的切分树布局。照片按顺序放入格子，切换模板保留照片。
- 支持八种画布比例，画布居中适应窗口；拖动内部公共分割线，所关联的一组格子实时联动。分割树限制最小格子尺寸。
- 单击照片选中，左键按住照片拖到另一格交换照片及其取景、裁剪和水印；默认右键拖动调整框内取景，滚轮或触控板捏合缩放。工具栏不再提供交换按钮。点击画布留白会取消选中并收起工具栏。
- 「软件设置 → 标准拼图」可将框内取景切换为按住空格、Option、Command 或 Control 加左键拖动；右键与键盘方式互斥，选定键盘方式才显示按键选择。普通左键拖动始终用于交换格子里的照片。
- 裁剪 / 水印沿用现有单图编辑器，从原图打开并保留编辑参数；保存结果单独缓存，导出使用完整编辑结果，原文件保持不变。替换照片只作用于当前格，重置该格取景，取消或读取失败保留原照片。
- 支持填满或完整显示、间距、外留白、圆角、背景色与背景图；左侧用实时绘制的缩略图选择模板。
- 导出 PNG / JPEG，按设定比例读取原图生成结果；原图移位或失效会显示具体文件名。已有目标文件不会被覆盖。

模型、模板、渲染器和 macOS 界面分别位于 `GridCollageModel.swift`、`GridCollageTemplates.swift`、`GridCollageRenderer.swift`、`GridCollageView.swift`。模型和渲染器不依赖 AppKit；当前只提供 macOS 界面。参考拼图大师公开页面的功能，自主实现，未复制其脚本或素材。当前模板均为嵌套横纵切分；尚不包含斜线、曲线或无法用切分树表达的交错布局，也不宣称已复现网站全部功能。

## 长图拖拽设置

长图默认右键拖动整个画布，左键拖照片调整顺序。「快捷键与导出」中可改为按住键盘快捷键加左键拖动画布；两种方式只能选择一种，顶部提示只显示当前生效的方式。选择键盘方式后可选空格、Option、Command 或 Control。标准拼图的框内取景快捷键独立保存，不会随长图设置改变。旧版本同时开启两种方式的设置会迁移为默认右键；旧版本只开启键盘方式则保留原来的按键。

## 兼容性

应用显示名和构建产物恢复为 `AoiStitcher` / `AoiStitcher.app`。为保留旧设置与 Xcode 工程兼容，bundle ID `polo-aoi.AoiStitcher`、`AoiStitcher.xcodeproj`、scheme 保持不变。项目资料默认保存在 `~/Pictures/AoiStitcher 项目/`，可在「软件设置 → 通用 → 项目存储位置」更改，重启后生效。启动时会迁移 `~/Library/Application Support/aoipic/Projects/` 中的旧项目；纸张与水印素材路径保留。

新项目只创建 `project.json` 和按需生成的隐藏缓存，不再创建空的 `Originals` 文件夹。资料自动保存原图路径、来源文件夹、排序、分组、两侧缩略图大小、联动状态和导出记录。旧项目已有的 `Originals` 副本继续读取，不会自动删除；重复导入选择「替换项目素材」后，该素材改为引用新导入的文件，旧副本及原文件内容保持不变。旧坐标及浏览缩放字段继续保留兼容，旧项目按原先由上到下、从左到右的位置迁移素材顺序。旧星级和颜色字段读取时忽略；包含这些字段或旧压缩导出记录的项目仍可读取和保存。拼图编辑草稿仍只在当前会话保留；切换工作区保留编辑状态，切换到另一项目或关闭应用后不保留。切换项目只有在存在未导出编辑时才提示，导入或导出期间停用切换。导出的成品留在用户选择的路径中。
