# AoiStitcher for Mac · 3.0

AoiStitcher 是免费的 Mac 照片拼图工具，使用 Swift / SwiftUI 和 AppKit 开发。3.0 保留长图拼接，并新增自由画布、纸张底图、图层操作，以及重做的裁剪工作台。

## 3.0 更新

- **自由画布**：支持多张照片和纸张自由摆放、缩放、旋转；提供双图左右排、上下排、留白与间距设置。
- **画布与底图**：内置纯色色纸、米色纸、纤维纸和方格纸，也能导入自己的底图；支持自定义颜色、画布尺寸和横竖切换。
- **素材图层**：单击选择、右击设置、拖动列表改变层级，支持锁定、复制、删除和撤销。
- **新版裁剪**：双击照片进入。八个手柄调整范围，框内拖动照片，框外缘和顶部手柄拖动旋转；支持固定比例、拉直、水印与撤销，保存使用原图像素。
- **统一界面**：长图拼接和自由画布共用侧栏、工具栏及导出控件。导出设置默认收起，导出成功后可直接清空画布。
- **设置与关于**：可恢复默认偏好，查看作者介绍、联系方式，并通过微信或支付宝自愿打赏支持。
- **通用 App**：同一份 App 同时包含 Intel（x86_64）和 Apple Silicon（arm64）代码。

## 下载与运行

运行要求：**macOS 14.6 或更高**。

1. 下载 [3.0 通用 App ZIP](../../raw/main/dist/AoiStitcher-Universal-unsigned.zip)。
2. 解压，将 `AoiStitcher.app` 移动到「应用程序」。
3. 本构建没有 Developer ID 签名和公证。首次打开被 macOS 拦截时，可在「系统设置 → 隐私与安全性」中允许打开。

当前版本在会话内编辑，**退出后不会保存画布工程**，请先导出作品。恢复默认设置只影响软件偏好，保留当前画布和照片。

## 操作

- 自由画布：拖动素材移动，角点缩放，顶部手柄旋转；素材列表上方的行显示在更前面的图层。
- 素材列表右击打开参数，`Delete` 删除选中素材，画布获得焦点时 `⌘D` 复制；`⌘Z` 撤销，`⇧⌘Z` 重做。
- 画布获得焦点时，空格加拖动平移，`Option` 加滚轮或双指捏合缩放，`Q` 适合窗口；方向键移动素材，`Shift` 加方向键移动 10 像素。
- 裁剪框内拖动照片，`Command` 加拖动移动裁剪框；框外缘拖动旋转，`Shift` 按 15° 调整。回车应用，`Esc` 取消。
- PNG / JPEG 格式和导出宽度在导出设置中调整，两个编辑模式共享这些偏好。

完整操作和限制见 [测试说明](AoiStitcher/测试说明.md)。

```sh
zsh scripts/build-universal.sh
```
