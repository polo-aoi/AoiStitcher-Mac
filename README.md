# AoiStitcher 3.3.0

原生 macOS 拼图应用，包含「项目素材」「标准拼图」「自由画布」「长图拼接」四部分。可先以项目素材库组织照片，再选择工具完成拼图；照片已经选好时，也可从首页直接进入拼图。双图拼接并入自由画布，保留左右排、上下排等快捷排版，以及纸张库、裁剪、水印和旧设置。

应用名称恢复为 AoiStitcher。边框工作区已移除；图片压缩与输出锐化移至独立应用 **AoiGlow**，工程位于 `/Users/aduo/Documents/aoiglow`。主程序保留旧项目和素材资料，也保留旧项目中的压缩导出历史。

标准拼图布局模板位于左侧，画布顶部以加减按钮调整格子数；删除单张照片保留空格，减少有照片的格子先确认。照片旁的工具栏集中提供裁剪 / 水印、替换、填充方式、重置取景与删除。画布样式可恢复默认（间距 8、留白 16、圆角 0、白色底色，保留背景图片）。

当前交互调整：标准拼图直接左键拖动照片到另一格交换位置，右键拖动调整框内取景，移除工具栏的交换按钮。长图和标准拼图各自提供互斥的右键 / 键盘拖拽设置，默认右键；选择键盘后才显示具体按键选项。

最新顶部入口与分组引导（2026-11-05）已通过 Debug（arm64）构建及 14 组、847 项项目素材回归。未启动实际应用，完整弹窗交互与视觉效果见 `测试说明.md` 顶部发送专项。

## 使用

启动后显示项目首页，顶部是左右等宽、等高的虚线圆角卡片。左侧「创建图片项目」用于先整理、挑选和分组，再拼图；整块可点击选择文件夹或多选图片，也可直接拖入文件夹或图片，照片保留在原始位置。不再提供右上角新建按钮、仅填写名称的创建窗口或其他空项目创建入口。导入文件夹时使用文件夹名称创建项目。双击项目卡片进入项目素材，单击不打开；右键仍可选择「打开」。项目按创建时间从新到旧固定排列，卡片显示创建日期；打开、浏览、编辑及重命名都不改变顺序，新项目插入列表前方。

右侧「直接开始拼图」提示「无需创建项目，进入后即可添加照片」，提供「标准拼图」「自由画布」「长图拼接」三个入口。点击按钮直接进入对应的空编辑器，再使用工具内的导入按钮或从访达拖入图片；首页也可把图片拖到对应按钮，带图进入工具。标准拼图最多 16 张，首页拖入无效内容或超过上限时保留首页，不新增项目。直接拼图时顶部同样保留「项目素材」及三个工具；项目素材初始为空，可导入照片或文件夹、分组并发送到工具，切换页面保留本次内容。临时素材和分组仅在当前会话中保留，不出现在首页项目列表中。有临时素材或尚未导出的作品时，返回首页会先确认；空会话直接返回。完成后请导出需要保留的成品。

三个拼图工具没有照片时使用同一空白引导，图标、文字、背景及居中位置一致，提示从本地导入、拖入或从「项目素材」添加。标准拼图没有照片时不显示可点击的占位格，点击空白不弹出选图窗口；已有照片后，通过加减格数产生的空格仍可点击添加照片。

首次进入或返回首页时，项目卡片不自动显示蓝色焦点框；实际单击卡片或主动按 Tab 导航后才显示，双击打开保持。悬停「创建图片项目」整卡或右侧三个拼图按钮时，底色与边框加深，图标轻微放大，约 0.15 秒过渡；不改变布局或拖入范围，并遵循系统「减少动态效果」设置。

主窗口原生标题栏右侧始终保留一个设置齿轮，在首页、项目素材及三个拼图工具中均打开同一「软件设置」窗口，⌘, 也可打开。各编辑器侧栏顶部只保留添加照片／纸张等操作，移除重复的应用名称、日夜切换和局部设置齿轮。外观与关于信息集中在设置的「通用」页；更改外观同步到所有页面，返回工具保留当前编辑内容。

已有项目可拖入图片、文件夹，或点击「导入素材」；文件夹及子文件夹按自然名称顺序读取，跳过非图片、隐藏文件、资料包和符号链接。同一批拖入的重复路径只导入一次。项目只记录原图位置，不复制或移动原文件。原图移动后可在首页右键「修复项目…」，选择新位置重新连接。

首页右键「在访达中显示」会定位最初导入的原始文件夹，照片都在子文件夹中时也保留导入根目录；多个来源可定位多个文件夹。旧项目根据已记录的原图路径定位其所在文件夹。没有可用原始位置时显示提示，不会打开软件内部的 UUID 项目资料目录。封面预览与素材缩略图统一写入隐藏的 `.thumbnails/v2` 缓存目录。

中间显示全部未分组素材，网格随容器宽度自动换行，只纵向滚动。支持 Shift／⌘ 点击切换选择、框选和多张拖动排序，拖动时显示插入位置。窗口或分栏变窄不会产生横向滚动条，缩放和换行不改变保存的顺序。单张或多张照片均可从素材区拖入已有组、从一个组拖到另一个组，或从组内拖回素材区；已有组的照片区、组号及行内留白都属于该组的追加区域。选中一张或多张照片，拖到右侧照片组区域的组外空白处、按回车或使用素材右键「新建组」，即可新建一组，这些照片离开原区域。空列表、组间空隙和末组下方空白均可接收单张或多张照片建组；未选择有效项目照片时不建组，访达文件及整组排序载荷不用于空白建组。组内可以选照片、拖动排序，按 Delete 按素材原顺序归还；点击组号选择整组后同样可按 Delete 归还，空组自动消失。组顺序和成员顺序自动保存，⌘Z 可撤销。

工具栏提供「素材滑块＋锁头＋分组滑块」。默认锁定，任一滑块同步调整两区；解锁后独立调整，重新锁定时先保留两边大小，下次拖动才以该侧数值同步。两侧大小与锁定状态随项目保存，旧项目继承原缩略图大小并默认联动。素材区触控板捏合等同调整左滑块，遵循锁定状态。组行高度随右滑块变化；图片内边距为 3pt，组内卡片间隔为 2pt，素材网格间隔为 6pt。缩略图尺寸及完整显示比例保持不变，竖图仍会保留比例带来的留白。拖拽预览使用当前显示尺寸和鼠标抓取位置，多张显示叠放与数量。照片不叠加导出角标；星级与颜色标签已移除。悬停可查看处理状态，素材信息弹窗已移除。选中照片按空格打开原图快速预览，顶部保留关闭和全屏，移除左右切图按钮；←／→ 按顺序切图，↑／↓ 按素材网格切到上一行／下一行同列照片，对应位置没有照片时停留。多选可逐张浏览，再按空格或 Esc 关闭，选择停在最后查看的照片。

顶部「标准拼图」「自由画布」「长图拼接」统一承接选中的照片，右侧照片组只保留标题与列表，不再重复显示「添加至」按钮。素材区、组内照片与整组选择均可直接点击顶部入口带图进入工具；未选择照片时仅切换工作区，编辑器之间切换不重复发送素材。顶部下方显示选图提示，选中后显示张数，三个入口柔和亮起一次并保留淡蓝描边；继续增选不重复动画，清空选择或进入编辑器后恢复普通导航。系统「减少动态效果」开启时仅显示静态描边。点击组号选择全部组员时，组号高亮为蓝色，照片分别显示圆角选框；整行保持普通浅灰圆角边界和正常底色，不增加整行蓝色外框或蓝色底色。组号、组行空白及实际照片的右键菜单统一为四项：添加至标准拼图、自由画布、长图拼接，以及「移回素材」。右击组号或行内空白时，四项操作作用于右击的整组；右击实际照片时，沿用照片选择规则，作用于所选照片。组内右键不再显示撤销、导入及旧组管理选项，中间素材区右键菜单保持。素材区或组行获得焦点时，1／2／3 仍分别添加选中照片至三个工具；点击组号后可快捷发送整组。也可把中间照片拖入已有组、将组内照片拖回中间。中间区域 Delete 从项目移除，右侧 Delete 仅退回素材；均可撤销且保留原文件、旧项目已有副本和导出历史。访达图片可直接拖入三个拼图工具。

所有添加入口共用同一流程：未分组照片先询问是否创建照片组，提供「创建照片组并继续」「直接继续」与「取消」，解释分组会将照片整理到右侧，方便整组复用。勾选「不再提示分组，以后直接继续」后，后续跳过此步骤且不会自动建组；已分组照片也直接进入原导入流程。空工作区直接导入；已有内容时，在同一弹窗的下一步确认顺序，并选择「继续添加」「清空后导入」或「取消」，支持返回上一步。分组和提示偏好只在最终发送成功后保存，中途取消保留照片选择、分组和编辑内容。标准拼图最多 16 张，追加超限时只能替换或取消；忙碌检查、未导出提示与读取失败保留旧内容的逻辑继续生效。

成功导出的用途记录和悬停处理状态保留，取消或失败不增加记录；旧项目的导出历史继续兼容保存。项目素材已移除「筛选」按钮、条件弹窗及按拼图方式／导出状态筛选的逻辑，中间区域始终显示全部未分组素材。导出记录页面和入口继续保持移除。照片历史与工作区当前状态分别记录：修改作品后重新提示待导出，选中、缩放查看和平移视图不影响处理状态。标准拼图按格数筛选布局模板的功能保持。

项目名称、四个功能入口和两侧栏按钮合并在同一行。左侧按钮展开项目列表以切换项目，列表同样按创建时间从新到旧排列；创建项目统一回到首页使用虚线导入区。右侧按钮展开／收起照片组，收起后按回车建组会自动展开。分界线平时为 1px 浅灰线，悬停／拖动时为 3px 主题色线，并显示系统左右调整光标；8pt 可抓取范围，松手记住宽度，窗口变窄不覆盖宽度偏好。项目列表、素材区和照片组使用无背景轨道的半透明圆角悬浮滚动条，不挤占布局，滚动或悬停时显示。素材工具栏已移除名称搜索框与素材筛选，移除「整理对齐」，「导入素材」右侧紧接素材滑块、联动锁和分组滑块；撤销使用 ⌘Z。功能默认顺序为「项目素材」「标准拼图」「自由画布」「长图拼接」。在「软件设置 → 通用 → 顶部功能排序」中拖动条目或点击上下箭头，可调整后面三个入口的顺序，立即生效并在重启后保留；点击「恢复默认顺序」会回到上述排列。旧排序自动忽略边框、压缩及重复入口，保留其余工具的自定义顺序并补齐缺失项。排序时保留当前工作区与各工作区已经导入的素材和编辑状态。

## 自由画布与快捷排版

本轮素材库与多图排版（2026-11-01）已通过 Debug（arm64）编译，以及画布模型和包含素材库的新回归代码类型检查。未执行自动测试、未启动应用；悬停预览、颜色面板及滑块的实际交互见 `测试说明.md` 的自由画布验收项。

自由画布选中照片后，在照片附近显示与另两种拼图一致的小工具条，仅保留裁剪／水印、替换、删除；画布照片与左侧对应图层的右键菜单使用同样三项。点击空白处取消选择。照片位置、大小和旋转直接拖动手柄调整，图层顺序通过左侧列表拖动；不再显示大号素材参数面板。替换保留位置、宽度、旋转与图层顺序，按新照片比例调整高度，支持撤销；取消或读取失败保留原照片。选中纯色或纹理纸张时，列表下方仍可调整纸张颜色。

自由画布默认鼠标滚轮围绕指针缩放，右键拖动平移，右键单击照片打开操作菜单。触控板双指滚动默认平移，捏合缩放。「软件设置 → 自由画布」可独立调整滚轮与连续滚动行为、缩放灵敏度和方向，以及右键／快捷键加左键的互斥平移方式；发送连续滚动事件的触控鼠标可将连续滚动设为缩放。画布绘制限制在编辑视口内，缩放和平移不会覆盖工具栏。

单张、双张和多张照片均可使用「左右排／上下排」：横排统一高度，竖排统一宽度，按当前图片比例计算，相同比例但不同分辨率的照片显示大小一致。画布尺寸保持不变，整组照片按留白与间距适应画布并居中。间距数值与滑块同步，拖动时实时调整照片实际边缘的距离，一次拖动可一次撤销；不再提供两图区域比例。手动移动、缩放、旋转、裁剪或增减照片后暂停自动排版，再次点击方向按钮即可恢复。

纸张「素材库」直接位于左侧栏，以文字行和可折叠的多级文件夹组织，悬停约 200ms 显示图片预览，单击立即使用。库内「＋」统一提供导入图片、导入文件夹、新建文件夹和新建纯色纸张；不再显示顶部「添加纸张」菜单或画布底色／色板。纯色纸张可命名、选色或输入 HEX，并保存后重复使用。素材由用户自行添加，不预装个人素材；已有纸张库继续读取。单击默认替换选中的纸张，否则替换最底层纸张；右键「添加新背景图层」可追加，不再重复显示使用项。画布中的已有内容单列为「画布图层」。

素材库图片右键「裁剪…」进入纸张裁剪界面，默认自由比例，可拖动四边／四角、选择比例和旋转。完成后选择「保存并替换」或「另存为新纸张」：替换保留名称和文件夹，永久删除库内被裁掉的像素，同步当前画布及其历史中引用该纸张的图层；另存在同一文件夹新增“原名 裁剪”，保留原素材，画布不自动换图。裁剪结果保存为保留透明度的 PNG，来源文件不变；保存失败保留裁剪状态及旧图片。纸张裁剪调整已通过 Debug（arm64）编译与相关回归代码类型检查，未执行测试或启动应用。

## 标准拼图

- 支持 1–16 格，按格数筛选模板；2–16 格各有六种自主实现的切分树布局。照片按顺序放入格子，切换模板保留照片。
- 支持八种画布比例，画布居中适应窗口；拖动内部公共分割线，所关联的一组格子实时联动。分割树限制最小格子尺寸。
- 单击照片选中，左键按住照片拖到另一格交换照片及其取景、裁剪和水印；默认右键拖动调整框内取景，滚轮或触控板捏合缩放。工具栏不再提供交换按钮。点击画布留白会取消选中并收起工具栏。
- 「软件设置 → 标准拼图」可将框内取景切换为按住空格、Option、Command 或 Control 加左键拖动；右键与键盘方式互斥，选定键盘方式才显示按键选择。普通左键拖动始终用于交换格子里的照片。
- 裁剪 / 水印沿用现有单图编辑器，从原图打开并保留编辑参数；保存结果单独缓存，导出使用完整编辑结果，原文件保持不变。替换照片只作用于当前格，重置该格取景，取消或读取失败保留原照片。
- 支持填满或完整显示、间距、外留白、圆角、背景色与背景图；左侧用实时绘制的缩略图选择模板。
- 导出 PNG / JPEG，按设定比例读取原图生成结果；原图移位或失效会显示具体文件名。已有目标文件不会被覆盖。

模型、模板、渲染器和 macOS 界面分别位于 `GridCollageModel.swift`、`GridCollageTemplates.swift`、`GridCollageRenderer.swift`、`GridCollageView.swift`。模型和渲染器不依赖 AppKit；当前只提供 macOS 界面。参考拼图大师公开页面的功能，自主实现，未复制其脚本或素材。当前模板均为嵌套横纵切分；尚不包含斜线、曲线或无法用切分树表达的交错布局，也不宣称已复现网站全部功能。

## 长图拖拽设置
