# aoipic 3.2.2

在现有 AoiStitcher 工作树上持续开发的原生 macOS 应用。以项目素材库组织照片，再进入边框水印、自由画布、长图拼接、图片压缩和标准拼图五个工作区。双图拼接并入自由画布，保留左右排、上下排等快捷排版，以及纸张库、裁剪与水印和旧设置。

3.2.1 修复标准拼图的空状态文字重叠；均衡网格置首并作为初始布局。选中照片可打开单图工具，进行裁剪 / 水印、单格替换、交换位置和重置取景；普通拖动仍用于格内取景。画布样式提供恢复默认按钮（间距 8、留白 16、圆角 0、白色底色，保留背景图片）。标准拼图始终在网格中编辑，任意位置摆放请切换自由画布。

3.2.2 精简标准拼图界面：布局模板移到左侧，移除重复的图片列表、单图参数区和比例选择区。画布顶部以加减按钮调整格子数；删除单张照片保留空格，减少有照片的格子先确认。照片旁的工具栏集中提供裁剪 / 水印、替换、交换、填充方式、重置取景与删除。

当前交互调整：标准拼图直接左键拖动照片到另一格交换位置，右键拖动调整框内取景，移除工具栏的交换按钮。长图和标准拼图各自提供互斥的右键 / 键盘拖拽设置，默认右键；选择键盘后才显示具体按键选项。

## 使用

启动后先显示「新建项目」和最近项目。把文件夹拖到首页或新建窗口，即可用文件夹名称创建项目并导入照片，也可以选择文件夹或先命名一个空项目。已有项目可拖入图片、文件夹，或点击「导入素材」；文件夹及子文件夹按自然名称顺序读取，跳过非图片、隐藏文件、资料包和符号链接。同一批拖入的重复路径只导入一次。原图会复制到项目，之后移动外部原文件不影响这些素材。

素材可自由摆放、留出间隔，支持单选、⌘ 多选、空白处框选、整组移动和撤销。「整体缩放」同时缩放图片和间距，不改素材坐标；「显示全部」适应当前筛选结果。照片上不叠加导出角标或状态文字；悬停可查看各工具的导出次数，星级与颜色标签位于文件名下方，可通过工具栏的显示选项隐藏；右侧素材信息默认收起，可点击工具栏按钮展开或双击照片查看。「整理对齐」按当前窗口宽度与缩放排列，只有明确点击整理才重新排列已有素材。

选择素材后，点击、拖入底部工具入口，或右键「发送到」标准拼图、自由画布、长图拼接、图片压缩。底部四个入口按顶部工具的相对顺序排列，普通鼠标悬停、按下和拖入都有反馈。空工作区直接导入；已有内容时，在同一窗口确认本批顺序，并选择「继续添加」「清空后导入」或「取消」。窗口说明当前内容是否有尚未导出的修改；替换会先检查新图片，失败时保留旧内容；标准拼图追加超过 16 张时停用追加。素材库的摆放位置不变。

右键支持批量评分、标色和「从项目移除」。素材区获得焦点时，0–5 设置星级，6–9 设置红／黄／绿／蓝标签，紫色在菜单选择，Delete 移除，⌘Z 撤销，⌘I 导入；编辑名称或搜索时不触发这些操作。移除只从项目视图隐藏素材，不删除电脑原文件，并保留项目副本和历史供撤销与导出记录使用。移动、评分、标色、移除共用会话内撤销。

这四个工具成功写出图片后，记录素材、用途、时间和输出路径；取消或失败不增加记录，批量输出按实际成功项记录。顶部提供全部／未导出／已导出数量，用途筛选可与星级、颜色和名称搜索组合，筛选不改摆放位置。选中照片可查看相关导出并在访达定位，历史可反选仍在项目里的素材。照片历史与工作区当前状态分别记录：修改作品后重新提示待导出，选中、缩放查看和平移视图不影响处理状态。

项目内顶部固定显示「项目素材」，其后默认依次为「边框水印」「自由画布」「长图拼接」「图片压缩」「标准拼图」。在「软件设置 → 通用 → 顶部功能排序」中拖动条目或点击上下箭头，可调整后面五个入口的顺序，立即生效并在重启后保留；点击「恢复默认顺序」会回到上述排列。排序时保留当前工作区与各工作区已经导入的素材和编辑状态。

边框水印维持现有内置样式、素材列表和“提交效果 / 点餐”入口，暂不接入项目发送和处理记录；在设置中填写联系邮箱后，提交窗口点击“确定”会自动复制邮箱并显示反馈。压缩页多选导入图片或文件夹，也可从 Finder 拖入右侧列表。选择朋友圈、小红书、抖音或自定义，调整输出锐化，选择输出位置，然后点击「导出图片」。列表支持多选、移除所选、Delete、清空。导出期间显示文件名与进度，可停止；失败行可打开详情并单独重试。

朋友圈/小红书/抖音的质量自动决定，不提供质量选择；短边分别为 1920/2560/2160 px，小图不放大。抖音参数依据本机图适 4.7.1 的场景分支核对，详见 `AoiStitcher/Compression/抖音参数核对.md`。五档是输出锐化。自定义可调整尺寸、格式和质量；底部导出设置可调整拍摄信息、GPS、允许放大和导出后显示。没有图片预览、原图显示或前后对比。

## 自由画布与快捷排版

自由画布默认鼠标滚轮围绕指针缩放，右键拖动平移，右键单击照片打开素材设置。触控板双指滚动默认平移，捏合缩放。「软件设置 → 自由画布」可独立调整滚轮与连续滚动行为、缩放灵敏度和方向，以及右键／快捷键加左键的互斥平移方式；发送连续滚动事件的触控鼠标可将连续滚动设为缩放。画布绘制限制在编辑视口内，缩放和平移不会覆盖工具栏。

双图和多图在同一个「自由画布」中编辑，侧栏始终保留「快捷排版」。一至两张照片可设置留白、间距，再左右排或上下排；两张照片还可调整两图区域比例。排版后仍可直接移动、缩放和旋转照片。导入第三张及更多照片时继续留在当前画布，通过自由摆放编辑，快捷排版按钮停用。照片、纸张、裁剪、水印、撤销与导出沿用同一套编辑状态。

## 标准拼图

- 支持 1–16 格，按格数筛选模板；2–16 格各有六种自主实现的切分树布局。照片按顺序放入格子，切换模板保留照片。
- 支持八种画布比例，画布居中适应窗口；拖动内部公共分割线，所关联的一组格子实时联动。分割树限制最小格子尺寸。
- 单击照片选中，左键按住照片拖到另一格交换照片及其取景、裁剪和水印；默认右键拖动调整框内取景，滚轮或触控板捏合缩放。工具栏不再提供交换按钮。点击画布留白会取消选中并收起工具栏。
- 「软件设置 → 标准拼图」可将框内取景切换为按住空格、Option、Command 或 Control 加左键拖动；右键与键盘方式互斥，选定键盘方式才显示按键选择。普通左键拖动始终用于交换格子里的照片。
- 裁剪 / 水印沿用现有单图编辑器，从原图打开并保留编辑参数；保存结果单独缓存，导出使用完整编辑结果，原文件保持不变。替换照片只作用于当前格，重置该格取景，取消或读取失败保留原照片。
- 支持填满或完整显示、间距、外留白、圆角、背景色与背景图；左侧用实时绘制的缩略图选择模板。
- 导出 PNG / JPEG，按设定比例读取原图生成结果；原图移位或失效会显示具体文件名。已有目标文件不会被覆盖。

模型、模板、渲染器和 macOS 界面分别位于 `GridCollageModel.swift`、`GridCollageTemplates.swift`、`GridCollageRenderer.swift`、`GridCollageView.swift`。模型和渲染器不依赖 AppKit；当前只提供 macOS 界面。参考拼图大师公开页面的功能，自主实现，未复制其脚本或素材。当前模板均为嵌套横纵切分；尚不包含斜线、曲线或无法用切分树表达的交错布局，也不宣称已复现网站全部功能。

## 长图拖拽设置

长图默认右键拖动整个画布，左键拖照片调整顺序。「快捷键与导出」中可改为按住键盘快捷键加左键拖动画布；两种方式只能选择一种，顶部提示只显示当前生效的方式。选择键盘方式后可选空格、Option、Command 或 Control。标准拼图的框内取景快捷键独立保存，不会随长图设置改变。旧版本同时开启两种方式的设置会迁移为默认右键；旧版本只开启键盘方式则保留原来的按键。

## 兼容性

应用显示名和构建产物为 `aoipic`。为保留旧设置与 Xcode 工程兼容，bundle ID `polo-aoi.AoiStitcher`、`AoiStitcher.xcodeproj`、scheme 和旧偏好键保持不变。项目保存在 `~/Library/Application Support/aoipic/Projects/`，每个项目包含复制的 `Originals` 和 `project.json`，自动保存素材、坐标、浏览缩放、星级、颜色标签和导出记录。拼图编辑草稿仍只在当前会话保留；切换工作区保留编辑状态，确认返回项目列表或关闭应用后不保留。导出的成品留在用户选择的路径中。

压缩模块的来源、算法保留项与架构说明见 `AoiStitcher/Compression/README.md`。该实现不宣称已经与图适完全一致。

## 构建和验证

要求 Xcode 26.2；运行最低 macOS 14.6。构建 arm64 + x86_64 通用包，使用本机 ad-hoc 签名，未做 Developer ID 公证。

本次项目素材库改动仅做代码静态检查，未进行编译、应用运行或界面测试；由用户在 Xcode 构建验收，步骤见 `测试说明.md`。下列命令供后续自行验证。

```sh
zsh scripts/test-canvas.sh
zsh scripts/test-compression.sh
zsh scripts/test-grid-collage.sh
zsh scripts/test-grid-collage-render.sh
zsh scripts/build-universal.sh /Users/aduo/Documents/AoiPic
```

构建脚本会保留输出目录中已有的 aoipic.app 到单独的 previous-build 目录，不静默覆盖。

本次没有移动端、收费、100 张额度或云同步；代码和图片处理均在本机。纸张库支持本地导入、保存、分页、排序和拖入画布，纸张底图最多 5 层且始终位于照片图层下方。边框工作区的批量边框渲染、水印库和多级资源文件夹仍在后续阶段。
